# 分诊标签

工程技能使用五种规范化分诊角色。本文件将这些角色映射为本仓库实际使用的标签。

| 技能角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估该 Issue。 |
| `needs-info` | `needs-info` | 等待提交者补充更多信息。 |
| `ready-for-agent` | `ready-for-agent` | 需求完整，可交由 Agent 实现。 |
| `ready-for-human` | `ready-for-human` | 需要人工判断或实现。 |
| `wontfix` | `wontfix` | 不会处理。 |
