# Triage 分诊标签

工程技能使用五种标准分诊状态。本文件将这些状态映射到当前仓库使用的 GitHub 标签。

| 标准状态 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Issue 尚未评估，需要维护者进行分诊 |
| `needs-info` | `needs-info` | 信息不足，正在等待提交者补充 |
| `ready-for-agent` | `ready-for-agent` | 内容和边界已经明确，可以交给 AI Agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要人工判断或人工实现 |
| `wontfix` | `wontfix` | 已决定不处理该 Issue |

当技能提到某种分诊状态时，应使用表中对应的 GitHub 标签。

如果仓库未来更改了标签名称，只需修改表格中的“GitHub 标签”列，不要更改标准状态列。
