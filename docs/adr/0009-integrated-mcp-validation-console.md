# 网关内置 MCP 验证台

首版在管理端提供只面向当前网关的 MCP 验证台，而不支持外部 MCP Server 探测。验证台以管理员临时粘贴、仅在当前页面会话内保存的完整 Agent API Key 建立真实 MCP Client 连接，再由 OpenAI SDK 驱动的服务端 Chatbot 通过对话调用 Tool；首版只连接 OpenAI 模型服务，模型名与 Base URL 放在 Nacos，模型 API Key 保留在本机或云端秘密配置，对话和调用记录不持久化。模型回复流式返回，页面将 Tool 的执行状态和结果内嵌展示；每轮模型请求仅附带当前页面最近 5 轮用户与助手对话作为上下文。Chatbot 决定调用 Tool 后，在该 Agent Key 的实际权限范围内自动执行，无需逐次人工确认；每条用户对话至多自动执行 3 次 Tool 调用。失败结果会继续提供给模型作后续判断，到达上限后不再调用第 4 次 Tool，模型据已有结果结束回复。管理员停止回复或离开页面时，只终止尚未完成的模型请求，不强制取消已发出的 MCP/下游业务请求。Agent API Key 只保留在浏览器页面内存，刷新即失效；前端仅在当次请求中临时传给后端，后端不保存。这既验证实际鉴权与协议链路，也避免把首版扩展为未知地址的外部 MCP 接入能力。
