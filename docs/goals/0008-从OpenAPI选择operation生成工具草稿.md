# Goal：Issue #8 从 OpenAPI 选择 operation 生成工具草稿

> 来源：[GitHub Issue #8](https://github.com/xiaoBaiJLong/ai-mcp-gateway/issues/8)
> 当前状态：阻塞，禁止执行
> Blocked by：#4、#7
> Goal 生成基线：`main@87257483071514516913c4b566eba5aad80cc9a6`

## Goal（目标）

让管理员从显式 URL 或 Nacos 服务获取 OpenAPI 3.x 文档，选择单个或标签 operation 生成可编辑草稿，并在刷新时查看差异而不自动发布。

## Current state（当前状态）

- 生成时无 OpenAPI 获取、解析、凭据、差异或 UI 实现，全部验收未完成。
- #4、#7 完成后才可激活；激活时刷新评论、HEAD、服务/工具模型、凭据边界和验证命令。

## Execution order（执行顺序）

1. 验证阻塞任务完成，记录固定点。
2. 用固定 OpenAPI 样例和可控 Swagger 服务先定义显式 URL、Nacos 探测、认证和解析失败测试。
3. 实现 OpenAPI 3.x 文档获取、固定凭据保存/不回显，以及常见路径自动探测。
4. 实现 operation 展示、单选/按标签选择和统一工具草稿生成，保留管理员编辑能力。
5. 实现手工刷新、可选定时检查、差异快照和“只生成草稿、绝不自动发布”约束。

## Completion criteria（完成标准）

- [ ] 可从管理员登记的完整 URL 获取有效 OpenAPI 3.x 文档。
- [ ] 可通过 Nacos 服务与约定路径探测有效 OpenAPI 3.x 文档。
- [ ] 受保护文档的固定凭据可保存，但保存后管理 API、界面和日志不返回完整凭据。
- [ ] 管理员可查看全部 operation，并按单项或 OpenAPI 标签选择。
- [ ] 被选择的 operation 生成带稳定名称建议、描述、参数和上游映射的可编辑工具草稿。
- [ ] 未选择的 operation 不生成草稿，导入与选择均不会自动发布。
- [ ] 刷新无变化时不制造虚假版本；文档结构变化时产生可检索差异和新草稿，不改变已发布工具。
- [ ] 无效文档、访问失败、鉴权失败和不支持结构返回可行动且不泄密的错误。
- [ ] 集成测试覆盖首次导入、刷新无变化、结构变化、显式 URL、Nacos 探测、鉴权和解析失败。
- [ ] 敏感值哨兵测试证明固定凭据不出现在普通 API 响应、前端状态和日志中。
- [ ] 相关测试、前端类型检查和仓库门禁全部通过。
- [ ] 已以激活时 HEAD 为固定点完成代码审查，无未解决高严重度问题。
- [ ] 全部标准通过后创建聚焦本 ticket 的本地提交，工作区干净。

## Constraints（限制）

- 不支持 OpenAPI 2.0、跨服务合并、自动发布或未经审核的权限扩大。
- 固定凭据首期允许明文存 MySQL，这是已接受风险；不得顺带引入加密平台或 Secret 管理。
- 文档 URL 必须属于管理员登记的受控来源，不能由 Agent 参数决定。
- 定时检查保持可选且简单，不引入调度中间件。
- 默认不 push、不关闭 Issue、不修改 tracker。
