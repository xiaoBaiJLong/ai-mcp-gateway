# Goal：Issue #15 提供可检索且脱敏的完整审计

> 来源：[GitHub Issue #15](https://github.com/xiaoBaiJLong/ai-mcp-gateway/issues/15)
> 当前状态：阻塞，禁止执行
> Blocked by：#10、#11、#13
> Goal 生成基线：`main@87257483071514516913c4b566eba5aad80cc9a6`

## Goal（目标）

记录并检索管理变更及本地/远程工具调用审计，使审计查看者可按调用 ID 还原行为，同时默认不保存正文并对凭据和敏感字段进行可靠脱敏与保留清理。

## Current state（当前状态）

- 生成时无审计模型、写入、查询、脱敏或保留清理实现，全部验收未完成。
- #10、#11、#13 完成后才可激活；激活时刷新评论、HEAD、管理/调用事件、错误模型、现有日志和验证命令。

## Execution order（执行顺序）

1. 验证全部阻塞任务完成，记录固定点。
2. 先定义登录、配置变更、本地/远程成功与失败调用的审计持久化和查询测试。
3. 实现调用元数据、控制面前后差异和按时间/Agent/工具/结果/调用 ID 查询。
4. 实现正文默认关闭、按工具开启脱敏正文、短期原始错误及 JSONPath/Header/字段名脱敏。
5. 实现可配置保留期限和只删除到期记录的清理流程，再增加 Vue 只读审计视图。

## Completion criteria（完成标准）

- [ ] 登录、上游、OpenAPI、工具版本、Agent、角色、工具集、发布、回滚、停用和权限变更记录操作者及前后差异。
- [ ] 每次本地和远程工具调用记录调用 ID、时间、协议版本、Agent、可选最终用户标识、工具/版本/风险、权限结果、目标、配置版本、结果、耗时、重试和大小。
- [ ] 审计查看者可按时间、Agent、工具、结果和调用 ID 通过公开 API 与界面检索记录。
- [ ] 审计查看者不能修改审计或其他平台配置。
- [ ] 完整参数和响应正文默认不保存；按工具开启时只保存脱敏内容。
- [ ] Token、API Key、Cookie、Authorization、固定远程凭据和标记敏感字段不进入普通审计正文。
- [ ] 脱敏规则至少支持 JSONPath、Header 名和字段名匹配。
- [ ] 默认保留期为元数据 180 天、脱敏正文 30 天、原始错误 7 天；管理操作与发布历史长期保留且期限可配置。
- [ ] 清理任务只删除已超过对应保留期的记录，不删除仍在保留期内的数据。
- [ ] 集成测试覆盖管理变更、本地/远程调用、失败、查询过滤、正文开关和保留清理。
- [ ] 敏感值哨兵扫描数据库查询结果和界面响应均无未脱敏凭据。
- [ ] 相关测试、前端类型检查和仓库门禁全部通过。
- [ ] 已以激活时 HEAD 为固定点完成代码审查，无未解决高严重度问题。
- [ ] 全部标准通过后创建聚焦本 ticket 的本地提交，工作区干净。

## Constraints（限制）

- 不实现外部 SIEM、不可篡改存储或默认保存完整业务正文。
- 网关记录最终用户上下文不代表其身份已被网关验证。
- 原始错误只能短期、受限保存，不能进入普通日志或普通审计展示。
- 使用 MySQL 和简单定时清理，不引入归档中间件。
- 默认不 push、不关闭 Issue、不修改 tracker。
