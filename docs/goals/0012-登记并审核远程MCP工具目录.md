# Goal：Issue #12 登记并审核远程 MCP 工具目录

> 来源：[GitHub Issue #12](https://github.com/xiaoBaiJLong/ai-mcp-gateway/issues/12)
> 当前状态：阻塞，禁止执行
> Blocked by：#3、#4、#5
> Goal 生成基线：`main@87257483071514516913c4b566eba5aad80cc9a6`

## Goal（目标）

让管理员登记远程 MCP 服务，使用无认证或固定 Bearer/API Key 手工同步 `tools/list`，查看差异，并只将人工审核发布的工具纳入本地授权目录。

## Current state（当前状态）

- 生成时无远程 MCP 登记、客户端、凭据、目录快照或差异审核实现，全部验收未完成。
- #3、#4、#5 完成后才可激活；激活时刷新评论、HEAD、本地权限/工具版本模型、协议客户端和验证命令。

## Execution order（执行顺序）

1. 验证全部阻塞任务完成，记录固定点。
2. 用可控远程 MCP 先定义登记、认证、首次同步和凭据失败测试。
3. 实现远程服务地址、协议偏好及无认证/固定 Bearer/API Key 配置，确保保存后不回显。
4. 实现管理员手工 `tools/list` 同步、目录快照和新增/删除/Schema 变化差异。
5. 将选定差异生成本地草稿，经现有校验/发布后才进入工具集和 Agent 可见目录。

## Completion criteria（完成标准）

- [ ] 管理员可登记受控远程 MCP 地址、协议版本偏好和无认证/固定 Bearer/API Key。
- [ ] 可手工连接可控远程 MCP 并同步 `tools/list`，同步结果保存为可比较快照。
- [ ] 重复同步无变化时不生成虚假差异或版本。
- [ ] 新增、删除和 Schema 变化产生明确差异及可选择的本地草稿。
- [ ] 同步本身不修改已发布版本、不自动发布、不自动改变工具集成员或 Agent 权限。
- [ ] 只有审核并发布的远程工具才进入 Agent 工具目录。
- [ ] 两个来源的同名工具使用稳定服务命名空间避免冲突。
- [ ] 固定凭据首期可明文存 MySQL，但保存后不出现在管理 API、界面、日志或配置导出中。
- [ ] 集成测试覆盖首次同步、无变化、新增、删除、Schema 变化和人工发布。
- [ ] 认证测试覆盖无认证、Bearer、API Key 和错误凭据，并用哨兵验证不泄漏。
- [ ] 相关测试、前端类型检查和仓库门禁全部通过。
- [ ] 已以激活时 HEAD 为固定点完成代码审查，无未解决高严重度问题。
- [ ] 全部标准通过后创建聚焦本 ticket 的本地提交，工作区干净。

## Constraints（限制）

- 第一阶段只手工同步，不实现周期同步、自动发布、OAuth、Resources、Prompts 或远程采样。
- 远程工具变化不得自动扩大权限，这是不可绕过的安全边界。
- 凭据明文存储是 ADR-0015 的简单实现决定，不顺带引入加密平台。
- 本 ticket 不实现远程 `tools/call`。
- 默认不 push、不关闭 Issue、不修改 tracker。
