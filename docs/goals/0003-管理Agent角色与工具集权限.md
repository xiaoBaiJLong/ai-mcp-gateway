## Completion criteria（完成标准）

- [ ] 管理员可通过公开管理 REST API 创建和管理 Agent、角色、工具集及其明确关联。
- [ ] API Key 明文只在创建或重置响应中出现一次，数据库仅保存不可逆摘要。
- [ ] 重置后旧 API Key 立即认证失败，新 Key 可以认证。
- [ ] 一个 Agent 绑定多个角色时，允许工具集按并集计算。
- [ ] 没有明确授权的 Agent 得到空权限，不存在隐式允许或角色继承。
- [ ] 工具集按条件选择后保存为明确成员，未来新增工具不会自动进入已有工具集。
- [ ] 审计查看者可以查看上述配置，但所有修改请求均被拒绝且数据不变。
